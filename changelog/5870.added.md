- Added `ClassifierUserTurnStopStrategy` and `ClassifierUserTurnStrategies`, which let a classifier, such as `JevClassifier`, decide whether the user's turn is complete. They're an alternative to `FilterIncompleteUserTurnStrategies` for an LLM that doesn't follow the turn-completion markers well. Each time the user pauses, the strategy asks the classifier about the turn so far: `complete` lets the turn end, and `short` and `long` keep it open for a few seconds unless the user continues. The LLM only answers complete turns.

  ```python
  user_params = LLMUserAggregatorParams(
      user_turn_strategies=ClassifierUserTurnStrategies(
          classifier=JevClassifier(api_key=os.getenv("TYPESAFE_API_KEY")),
          context=context,
      ),
  )
  ```
